# MultiFlow website

Static files of https://liuq-lab.github.io/MultiFlow/: `index.html` (documentation), `explorer.html` (Attention Explorer) with its precomputed data in `data/`, and the downloads in `files/`.

The site is deployed by `.github/workflows/pages.yml` whenever `site/` changes on `main`. Nothing here is part of the Python package (see `MANIFEST.in`).
